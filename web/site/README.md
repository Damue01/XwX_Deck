# 官网本地预览

官网源码用于介绍产品和演示界面。
演示复用公开版前端。
账号、服务、额度和下载夹具均为示例。
演示不读取本机客户端配置或真实凭据。

## 构建与验证

在仓库根目录执行以下命令。

```sh
npm run build:site
npm run test:site
```

浏览器测试复用已安装的 Playwright。
可通过 `XWX_PLAYWRIGHT_MODULE` 指定该模块。
`XWX_SITE_PREVIEW_DIR` 可指定待验证的预览目录。

生成文件统一放在 `test-results/site-preview`。
该目录不提交到 Git。
源码目录不保存生成的 JavaScript、字体或应用快照。

## 下载与发布

下载地址默认留空。
未配置时，页面说明当前不可下载，并提供公开发布页入口。
仅填写已发布并核实的制品地址。
网页不宣称尚未发布的版本已经可用。

构建和测试只生成本地预览。
现有文档站与发布渠道保持原状。
部署官网需要单独的发布指令。

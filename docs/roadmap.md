# Roadmap

## 0.1.x

- 稳定独立 appId、数据目录、端口和构建流程；
- 验证 Claude / ChatGPT 官方与兼容服务的 Trace、模型切换和恢复；
- 验证分档/峰谷计费、实际服务模型名和缓存 TTL 用量读数；
- 持续复核当前 Gateway 实测能力，避免给模型展示无法兑现的推理档位；
- 验证快速修复、应用重置与强制退出恢复的跨平台安全边界；
- 完成公开许可证、隐私说明和安全报告渠道决策；
- 建立签名、公证和公共 HTTPS 更新服务后，再启用自动更新。

## 不在当前范围

- 客户端配置同步；
- 工具页；
- Excel / CSV 转 Markdown；
- 内部局域网发布与管理工具。

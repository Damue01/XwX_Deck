# Trace 默认状态与安装包修复

## 修改范围

新安装根据本机检测展示 Claude 和 ChatGPT。
已安装但配置为空时，默认不选中对应来源。
已有明确开关继续保留。
Trace 总开关仍由用户开启。

Trace 可以沿用 Codex 当前第三方连接。
接管只临时修改当前服务的地址。
保留服务身份、协议、模型和原客户端授权。
关闭时恢复直连，并保留无关字段的外部修改。
Deck 无需先导入连接或添加订阅。
本次不新增客户端导入引导。

签名 Mac 包移除首次放行说明。
安装页改用无边框箭头，并移除装饰分隔线。
公开版重新编号为 1.0.0。
本地候选单独构建、签名和公证。
构建不替换正常安装，也不发布线上版本。

## 验证范围

程序化回归覆盖空白安装、空文件和仅安装客户端。
同时检查第三方接管、授权传递、关闭恢复和开关重启。
这些回归使用隔离目录与合成上游，只计为 P。
真实授权 CLI 与实际应用操作按 R、U 单独登记。
最终包哈希和 Apple 公证结果记录在各自构建报告。
结果汇总在验证完成后补充。

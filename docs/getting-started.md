# 快速开始

> 适用于 XwX Deck 1.0.0 独立版。

还没有安装客户端或获取 API 密钥，请先打开 [下载与安装](./download.md)。以下以 ChatGPT 客户端中的 Codex 接入 DeepSeek 为例。

## 带入已有配置

首次打开先显示“导入已有配置”，检测 Magpie、CC Switch、旧版 Deck、Claude CLI 和 Codex CLI。选择需要的项目后点击“导入并继续”，没有配置可直接继续。原文件只读，已有同连接跳过，同名不同连接另存；导入前备份 Deck 配置，来源变化时要求重新检测。订阅登录需要重新授权，不迁移登录令牌。导入不会自动改变模型服务或客户端连接。之后也可从“设置 → 添加配置 → API 服务 → 导入已有配置”打开。

## 连接 DeepSeek

1. 打开 XwX Deck 的“设置”，在“模型配置”同一行点击“添加配置”，选择 DeepSeek。名称和官方 API 地址会填为 `DeepSeek` 与 `https://api.deepseek.com`；填入自己的访问密钥并保存。需要获取密钥时，可先点击卡片中的“获取 API 密钥”。
2. 打开“模型”页面，为 ChatGPT 选择刚保存的连接，再选择该服务提供的模型。需要重新打开客户端时，按页面提示操作。
3. 在客户端的 Codex 中发送一条新消息，确认收到回复。配置保存、模型目录可访问与实际调用成功是不同状态；保存后的验证提示可帮助定位密钥、地址或模型问题。

预填内容只是添加连接时的草稿，保存前不会创建 API 连接，也不会更改已有连接。“添加配置”提供官方 API 服务、Coding Plan、本机服务与自定义配置，选择后填写自己的密钥。已有同名连接时，新草稿使用不重复的名称。点击服务行可展开或折叠设置，折叠时保留未保存的输入。

DeepSeek 的官方接入方式见 [Codex 接入说明](https://api-docs.deepseek.com/quick_start/agent_integrations/codex/)。第三方 API 配置用于 Codex 的本地模型连接，不会替换 ChatGPT 网页普通聊天的模型。

## 查看请求与用量

回到 Trace，点击开始追踪，再在客户端发送一条新消息。打开仪表盘可查看请求模型、Token、耗时、内容与最终上游地址；费用为估算，以服务商账单为准。Trace 保存在本地，可能包含完整请求和响应内容，请按需开启。

停止追踪只停止记录，模型服务设置保持不变；需要协议转换的模型仍依赖后台 Gateway。托盘或菜单栏的“退出”会恢复仍由 XwX Deck 管理且未被外部修改的客户端字段，并执行安全停服；存在活动请求或工具续接时会先确认。XwX Deck 不会自动结束、启动或强制退出 ChatGPT。

独立版没有配置同步、工具页、ChatGPT 对话诊断与 Excel 转换。

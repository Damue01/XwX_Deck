# 五分钟使用指南

> 适用于 XwX Deck 0.1.x 独立版。

1. 启动 XwX Deck，确认 Trace 页面显示 Claude 与 ChatGPT 客户端状态。
2. 如需兼容模型服务，在设置中添加连接，填写名称、服务地址和密钥；必要时选择接口或填写模型 ID。
3. 在“模型”页面选择客户端和模型服务。
4. 回到 Trace，点击开始追踪，然后在客户端发送一条测试请求。
5. 点击仪表盘查看请求模型、Token、耗时、内容与最终上游地址。

关闭 Trace 会恢复仍由 XwX Deck 管理的客户端字段。托盘或菜单栏的“退出”执行完整安全停服；存在活动请求或工具续接时会先确认。XwX Deck 不会自动结束、启动或强制退出 ChatGPT。

独立版没有配置同步与 Excel 转换；“工具”仅提供只读的 ChatGPT 对话诊断。

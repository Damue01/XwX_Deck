# 交互与设计约定

本文件约束公开版后续修改。来源为本轮技术吸收的产品规范，并应用公开版边界；验收记录见 [技术吸收记录](upstream-port.md)。

## 服务与模型选择

- 用户最后一次明确选择是当前意图。目录请求失败、旧异步结果、Gateway 离线、切页和启动恢复均不得自动选择另一服务或模型。
- 保存服务和模型是本地配置操作。远端健康检查、模型目录与能力补全不能成为保存的前置条件。后续步骤失败时说明配置是否已写入，并提供重试、修复或打开连接设置的操作。
- 前台操作从实际提交时计时；正常本地写入完成后，目录等待最多占用总计 2 秒。超时释放界面，后台结果仅在连接与请求代次仍匹配时应用。
- Claude 和 ChatGPT 均先显示相同连接的缓存，再后台刷新。单个目录失效保留该目录的旧模型；全部失败保留完整最后成功缓存。晚到结果不能覆盖新连接、新模型和新输入。
- 服务明确声明 Responses 时优先直通；其次使用已声明的 Chat Completions 或 Messages；未声明时保留连接默认协议。禁止按名称或厂商猜测路由。
- 仅实际需要协议转换的模型显示灰色「需 Trace」。原生 Messages 不标为转换；Desktop 不接受原始模型名、需要别名转发时标「需 Trace」；徽标不阻止选择。切换和错误不清空上下文窗口、模型输入或连接表单。
- 新连接名称使用 1–80 位英文字母、数字、下划线或连字符，作为可持久化的 Provider 身份。已保存的旧名称原样保留；不因升级重命名或映射外部服务。

## 组件与布局

- 完整下载与安装说明集中在官网。模型页的客户端标签右侧固定显示「管理客户端」，不使用「…」菜单；标签较多时横向滚动。管理面板打开或重新回到应用时自动检测，并提供「重新检测」。已安装客户端可添加，未检测到时提供官方下载入口；检测本身不添加标签、不改模型配置。管理面板复用客户端下载目录，默认只显示图标和名字，确认未安装的图标与名称调淡但仍可点击，检测不可用时不推断为未安装；选择后在同一卡片的左侧列表、右侧详情中提供添加、打开与移除，不重复显示安装或检测状态。移除只隐藏标签，保留模型配置与服务选择，不卸载客户端；空列表仍保留管理入口。Claude Code / Codex CLI 与 Claude / ChatGPT 共用各自模型配置标签，旧版保存的同类标签合并，下载入口仍分别保留。其他已添加客户端显示独立的手动配置页面。检测只检查应用与可执行文件、已安装编辑器扩展，不把残留配置当作已安装，不读取登录凭证或运行安装命令。设置页将「＋添加配置」放在「模型配置」同一行，折叠时也能打开；展开后只显示已保存的配置，不增加重复的模型服务标题。两个页面标题旁不放全局添加按钮。切换客户端分别保留已有模型与服务选择。
- 「添加配置」只打开一个页面，提供「API 服务」「订阅账号」「客户端下载」三个平级标签，默认 API 服务。初始展示所有预设的「图标＋名字」和自定义入口，不显示搜索框；选中后在同一页面切换为左侧服务商列表、右侧配置，不叠加卡片。切换服务商、下载标签或关闭后重开保留各自未保存草稿；返回服务商目录不保存或清空草稿。
- 默认表单仅名称、URL 和 Key；预设填好合法名称、官方地址与明确协议，Key 留空并默认隐藏。保留可临时显示密钥和直接打开官方密钥管理页的操作。高级协议选择默认折叠，仅在已保存连接编辑或自定义配置中提供。
- 普通 API 与 Coding Plan 使用独立、明确命名的预设，不通过默认展开的服务类型字段混在一起。套餐身份持久化，修改 URL 不丢失身份；不得自动改写为普通按量入口。保存套餐配置只写本地，不自动发送模型测试消息；实际可用性由客户端新任务确认。模型目录请求失败不阻止保存，不修改最后一次服务或模型选择。新增预设使用独立官方文档，尚未支持的协议或认证方式不伪装为兼容预设。不提供百度或非官方中转预设。
- 客户端下载直接展示全部客户端，并在同一页面内选择客户端，官方下载均跳转官方的下载或安装页面；ChatGPT / Claude 额外保留默认折叠的 Windows / Mac 镜像。Codex CLI / Claude Code 下载目录各自保留 Windows 与 Mac / Linux 镜像安装脚本和可复制命令；Gemini CLI、Qwen Code、OpenCode 提供默认折叠的 npm 镜像。复制命令不执行安装、不改变系统包管理器设置。镜像仅列架构链接，明确系统选择不按运行主机改写，不增加推广页或额外弹窗。新安装没有 API 连接，选中预设与预填表单均不创建连接；保存前不改变已有选择，重复名称提供可编辑的数字后缀。
- 已保存的服务配置沿用 Trace 的折叠交互。整体收起、切换连接保留未保存输入；从连接错误提示进入设置时自动展开对应编辑器。

- 保留克制的页面、数字和开关动效；遵从系统减少动态效果。主题立即切换，不使用会阻挡连续操作的整页快照动画；保存按顺序处理，快速切换以最后一次选择为准，后台状态不得覆盖。
- 文案不用间隔点分隔，不新增装饰性小字、Toast 侧边线或文字按钮内转圈。
- 全应用不使用横向或纵向分割线，包括侧栏、标题、诊断与修复、弹窗、通知、仪表盘、Trace 详情与应用菜单。分组用留白、文字层级与背景表达；可操作控件保留自身轮廓与焦点反馈，图表和进度保留数据标记。
- 关闭会话历史管理始终提供恢复原分类的选择；没有备份时明确说明，取消不修改。

- 模型菜单使用紧凑的约 32px 行高、单层悬停背景和清晰选中状态；协议徽标使用共享 Badge。菜单避开可拖动标题栏。
- 提示应说明当前状态、失败原因和下一步操作。相同生命周期事件合并展示；后台请求过期或所属页面已离开时不弹出无关错误。
- 输入拥有可访问名称，密钥默认隐藏且可临时显示；失败后保留输入，关闭编辑器后恢复焦点。
- 明暗主题、收起侧栏和小窗口下均应可操作。复杂页面保留滚动位置与输入，不因切页重新请求整份历史数据。
- 公开版不提供工具页与 ChatGPT 对话诊断；会话历史管理继续保留；Trace 索引检查与修复收进设置的「诊断与修复」，不在 Trace 设置中单列。

## 启动、退出、修复与更新

- 开机启动先保存用户意图，再尝试系统注册。系统读取/注册失败保留原意图并提示；未知值不能当作关闭。
- 启动各读取独立且有界。设置迁移失败保留原文件和备份，管理器仍能打开进行修复；损坏配置不得自动重置为默认服务。
- 退出恢复仅修改本产品拥有且未被外部改动的字段。仍有客户端依赖本地端口时保留 Gateway 与恢复证据，不进行整文件强制覆盖。
- 只重置应用数据不关闭客户端。重置客户端配置需要界面列出检测到的进程，并由用户确认「关闭并继续」；进程身份变化时重新校验。清理工作等待管理器退出后由独立 worker 完成，再启动原应用路径。
- 便携更新完成文件替换后，自动启动失败必须保留新版和旧版备份，显示原安装路径及手动打开动作；不能回退旧版或杀掉可能仍在启动的新版。
- 修复保留证据，优先可重试的小范围操作。Trace 新配置默认上限 1 GB 并开启超出上限自动清理，已有明确容量与清理选择保留；手动删除和索引重建由用户发起。
- 关闭管理器窗口保留必要的后台 Gateway。明确停止 Trace 时恢复受管配置与当前远端选择，确认没有本地依赖后停服；外部配置冲突时保留 Gateway。运行中的客户端可能缓存旧地址，提示完整重启客户端；官方空闲直连不启动多余 helper。

## 更新行为

- 启动约 6 秒检查一次，已有手动检查或下载结果时不覆盖。白天不自动安装。
- Windows 便携版在本地时间 02:00–05:00 分散检查并静默下载；系统空闲至少 15 分钟、没有活动回复/工具续接且安全退出检查通过时，才允许自动安装。恢复原窗口可见状态。
- 取消的目标版本跨重启保留，不再夜间自动安装；用户主动重新下载可恢复该版本。后台更新不弹出下载提醒或安装确认。
- 下载与安装前复查同一公开源的版本、文件和校验信息；变化时停止并提示重新检查。检查失败不能显示已是最新；并发检查/下载/取消不覆盖新状态。
- 停止 Gateway 之前完成文件完整性、原 EXE 和目标目录可写检查。更新 worker 确认代码加载后，旧进程才退出。
- macOS 当前没有自动替换通道。只下载并校验 DMG；用户确认打开后走安全退出，再手动拖入“应用程序”。从应用程序启动后只清理与运行副本核对一致的安装映像；未完成安装或内容不一致时保留。
- 没有 Developer ID 签名和公证前，公开工作流不发布 ZIP 或 `latest-mac.yml` 自动更新源。

## 公开版范围

公开版不提供配置同步页面、规则/技能文件同步或 Excel 转换。模型页的 Claude Desktop 接入是默认关闭的模型连接选项；不包含上述配置同步功能。新安装 Provider 列表为空。品牌、应用 ID、数据目录、端口与发布渠道独立。

验收至少覆盖本地成功、目录离线、慢请求、快速连续选择、外部改动、损坏设置、退出恢复，以及真实渲染界面的主要操作。仅通过类型检查不足以证明交互正常。


添加配置保持一个窗口，顶层仅「API 服务 / 订阅账号 / 客户端下载」三个标签。三个标签均不显示搜索框，标签、左右栏、表单操作区和账号行不使用分割线；选中标签用浅色背景区分。API 服务默认图标与名称网格，选择后同层切换左侧列表、右侧三字段编辑；订阅账号直接展示账号列表与浏览器登录状态，不叠加一层卡片。Coding Plan 专用 Key 仍归 API 服务。模型选择沿用原有客户端模型页面，新增账号不会替用户自动切换来源；额度和套餐状态只展示可验证信息。

- 订阅账号的改名只修改显示名称，保留注册身份、登录凭证、客户端选择和模型。账号行显示哪些客户端正在使用；同类订阅只显示一个模型服务，按用户设置的账号策略轮换；默认用完再换，保留同一对话账号。额度未知不虚构数值，不合并套餐，不跨平台或自动变更模型。仅在上游明确拒绝且没有向客户端输出时尝试其他账号，流中断和不明确的网络失败不重放。Grok 使用已安装的官方 Grok Build，在本产品隔离目录完成登录与刷新；取消和登录错账号不能覆盖原凭证。订阅页提供 ChatGPT、Grok、GitHub Copilot、Claude 和 Cursor 的账号登录，不列 API Key 套餐或未实现的占位入口。Copilot 使用 GitHub 设备授权，Claude 通过官方 Claude Code 在隔离目录登录，Cursor 使用浏览器 PKCE 和独立 Connect 请求适配。账号名称和 Trace 容量使用文字下方的虚线提示编辑能力，虚线不是页面分割线。容量 Enter 或失焦保存、Escape 取消；保存配置展开时不自动聚焦表单或重复挂载编辑器。
- 本机服务直接列在 API 服务目录中，预填回环地址，Key 可留空；不向上游发送空的 Authorization 或 x-api-key，不借用客户端当前密钥。自定义继续承接中转配置，无额外的中转站标签。

- 新增订阅账号默认参与同类轮换，保留已有明确暂停选择；正常账号行不显示参与勾选或重新登录。暂停使用与退出登录收进账号的更多菜单，暂停保留授权并显示「已暂停」与「恢复使用」；固定账号策略选中时才显示单选控件。授权失效或退出后在账号行显示「登录」，凭证的正常刷新由后台完成。

- 预设与客户端下载使用离线打包的品牌 SVG，单色标识适配夜间模式，不以通用应用或服务器图标伪装品牌。本机目录保留 Ollama 和 LM Studio；llama.cpp、vLLM、LocalAI 从新建目录移除，但仍识别已有配置。Roo Code、Aider、Jan 从客户端下载目录移除。

- 模型服务菜单只列已配置的 API 服务、已添加订阅类别及已有外部配置，不再列「客户端自带登录」。没有选定模型服务时显示「选择模型服务」，保留客户端现有登录与直连配置，不自动匹配或替换。模型服务菜单不列恢复操作；撤销客户端接管只在「诊断与修复」中提供「恢复 Claude / ChatGPT 连接」，保留安全回到原路由的能力。服务与模型下拉使用按钮选择，不默认搜索或进入输入框；自定义模型名通过菜单里的「输入模型名称」显式打开编辑，离线目录与不在目录的明确选择仍可保留。API 配置和已添加订阅账号不创建同名客户端标签。

- 订阅账号空列表直接显示对应 Continue with 登录按钮，不显示「请在桌面应用中添加」或「尚未添加账号」。登录等待与失败信息仍保留。查看套餐用量统一使用已核实的官方页面：ChatGPT / Claude 用量设置、Grok 设置中的 Usage、Copilot 账号中的 Usage、Cursor dashboard；可在网页预览打开官网，不伪装已读取任何账号额度。

- 风险分级用于操作反馈：普通模型、服务和本地配置切换只显示 Toast，不为此停止监听或取消已开始的回答；已开始的请求保留原服务快照，新请求使用最后一次明确选择。用户明确停止 Trace 或退出正在使用的账号时允许打断，并说明结果。外部配置接管、不可恢复的数据删除和客户端配置重置需要确认具体影响，不能把普通切换升级为确认弹窗。
- 协议转换保留可携带的工具结果、截图和可见推理。流缺少结束事件、工具参数不完整或内容无法表示时明确失败，不制造完成事件，不盲目重发已输出内容或工具。跨服务续接依赖会话历史；已知外来加密压缩只能在恢复原上下文后替换，不能静默删除。原始 Trace 请求与转换记录分开保存。

- API 服务页内提供「导入已有配置」，在同一页面预览 Magpie providers.json 和 CC Switch SQLite / 旧版 JSON，可手动选择来源文件。只在用户选择后复制名称、协议、URL、API Key 和模型信息；预览不包含 Key。来源文件始终只读，不迁移配置同步、MCP、规则、技能、历史正文或登录令牌。已存在配置不覆盖，重名自动加后缀，保留当前服务、模型与客户端文件；来源或目标在预览后变化时拒绝写入并提示重新检查，失败回滚内存。多协议和多个 API Key 分别展示，不能完整迁移的认证或请求覆盖明确标出，订阅账号需要重新授权。

- 客户端重新检测期间刷新图标旋转、按钮禁用并提供可访问的忙碌状态；完成后显示简短 Toast，不增加常驻说明。VS Code 使用官方蓝色图标，夜间模式不反色。

- Trace 索引检查区分正常、未收录记录、条目计数不一致、索引损坏和原始文件缺失；正常索引不显示修复按钮。手动修复以 JSONL 为依据重建，保留原文件、旧索引备份和可用的历史统计元数据；预览后索引变化时拒绝覆盖，正在运行 Trace 时拒绝修复。无法恢复的无效记录与缺失原始文件如实提示。

- 异步开关保存期间保持本次目标状态并阻止重复提交，失败后回退并提示；需要确认的操作在用户接受前保持原状态。开关滑块只平移，不在按下或禁用时拉伸。

- 语言设置复用夜间模式的开关，内部显示中／英，不显示搜索或“跟随系统”选项。首次按系统界面语言选择，手动选择即时生效并持久化；配置名、模型 ID、账号名与密钥不参与翻译。语言资源仅包含文本，不随包引入转换工具或额外字体。

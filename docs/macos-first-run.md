# macOS 安装

使用 DMG 安装或更新，并从“应用程序”启动。

## 安装

1. 在 [发布页](https://github.com/Damue01/XwX_Deck/releases/latest) 选择 Apple Silicon 安装包。
2. 打开 DMG，将 `XwX Deck.app` 拖入“应用程序”。
3. 从“应用程序”启动，完成首次设置。

未列出 Intel Mac 制品时，不要使用其他架构代替。

## 更新

在应用设置中检查更新，并下载新版本。
应用完成下载和校验后，可点击“打开安装包”。
等待旧应用安全退出，再拖入“应用程序”并选择替换。

如果仍有活动请求，先按提示等待或停止。
替换完成后，从“应用程序”打开新版。
确认新版正常运行，再推出安装映像。

首次使用步骤见 [快速开始](getting-started.md)。

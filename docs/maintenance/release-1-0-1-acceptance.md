## 关闭行为

Mac 旧候选在 Trace 关闭时点击系统关闭按钮，会以状态码 0 结束进程。
此前只有 Windows 无条件隐藏主窗口，Mac 仍依赖 Trace 运行状态。
现在应用内关闭与原生关闭事件均直接隐藏主窗口，与 Trace 是否开启无关。
明确选择退出时仍执行原有退出与恢复流程，仪表盘关闭保持独立。

初轮补丁通过实际鼠标关闭及明确退出复核。
最终签名包另行完成 4 项原生关闭与恢复检查，覆盖 Trace 开、关两种状态及两条关闭路径。
恢复后完成 8 轮官方 Codex、Claude CLI 实际请求。
Windows 初轮候选已实际复核关闭按钮、Alt+F4 与托盘退出；最终制品结果分别记录。

## Windows

使用原生 Windows Runner 构建 Setup 和便携版，验证原生界面及隔离安装、升级、卸载。
首轮 205 项 Rust 单测通过，后端仅独立认证测试失败，其余测试返回成功。
该测试把刷新后的令牌有效期设为 62 秒，与程序提前 60 秒刷新规则仅相差 2 秒。
繁忙 Runner 启动多个助手时可能跨过该窗口，产生合法的新一轮刷新，导致严格令牌序号断言失败。
测试已改为在宿主停止时显式过期自有合成账号，保留 6 轮、每轮 4 个助手及每轮仅刷新一次的断言。
原来的真实时间过期检查仍保留；该修改不改变认证运行代码。
最终重跑结果待流程完成后补充。

Windows 联调机器没有配置可用的 Authenticode 证书。
Apple 证书不用于 Windows 签名，Windows 安装器与便携版仍需如实标记为未签名。
